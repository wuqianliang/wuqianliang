## 🚀 Selected Project

### Diff-Reg — ECCV 2024

**Diff-Reg: Diffusion Model in Doubly Stochastic Matrix Space for Registration Problem**

Diff-Reg formulates correspondence estimation as a diffusion and denoising process in the space of soft matching matrices.

Instead of directly predicting hard correspondences, the method progressively refines a doubly stochastic matching matrix, preserving multiple correspondence hypotheses during the registration process.

**Topics:** Point Cloud Registration · Diffusion Models · Optimal Transport · Correspondence Estimation
